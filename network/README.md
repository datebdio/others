## 计划分类

后续可继续增加：

- `cloudflare-speedtest/`：Cloudflare IP / 域名测速
- `dns-tools/`：DNS 查询、解析检查、批量测试
- `routing-tools/`：路由、延迟、链路分析
- `proxy-tools/`：代理相关辅助工具

> 一个功能尽量作为完整项目独立管理，不把同一项目的 `.sh`、`.bat`、配置文件拆到不同一级目录。
