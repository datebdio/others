# Templates

[← 返回仓库首页](../README.md)

这里存放 `others` 仓库的新项目维护模板。

## Project Template

长期维护的新项目优先参考：

[`project-template/`](project-template/)

它提供：

```text
README.md
AGENTS.md
CHANGELOG.md
agent-context/
├─ CONTEXT.md
├─ STATE.md
├─ DECISIONS.md
├─ HISTORY.md
└─ ROADMAP.md
```

创建项目时先复制维护骨架，再根据实际需要增加 `scripts/`、`config/`、`docs/`、`tests/`、`src/` 等目录。

不要为了模板完整创建没有实际内容的空目录。
