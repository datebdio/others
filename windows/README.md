# 🪟 Windows

[← 返回仓库首页](../README.md)

这里存放独立的 Windows 工具，包括 BAT、PowerShell、网络诊断、系统维护等。

## 项目列表

当前暂无独立正式项目。

> 如果某个 Windows BAT 属于一个跨平台项目，例如 VLESS + Cloudflare 的测速 BAT，则继续放在对应项目目录中，不单独拆到这里。

## 计划分类

- `network/`：Windows 网络工具
- `maintenance/`：系统维护
- `powershell/`：PowerShell 工具
- `batch/`：独立 BAT 工具

新增项目后，在本页加入项目说明、状态和跳转链接。
