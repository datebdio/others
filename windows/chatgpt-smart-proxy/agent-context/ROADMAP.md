# Roadmap

## 近期候选

- 真实 Windows 环境继续验证 v0.2 的后台无黑窗与多节点交互。
- 优化错误提示，将常见 Xray 启动错误映射成更易懂的插件提示。
- 增加节点批量导入/导出。
- 增加订阅 URL 支持和多配置文件管理。

## 可选增强

- 节点排序、备注与分组。
- 更准确的代理链路延迟/可用性检测，而不仅是 TCP connect。
- Edge 安装说明和兼容性专项验证。
- 为自动化打包增加版本参数/Tag/Release 发布能力。

## 非目标

- 不把项目扩展成完整系统级代理客户端。
- 不实现用于规避账号限制、风控、服务端保护或访问控制的功能。
