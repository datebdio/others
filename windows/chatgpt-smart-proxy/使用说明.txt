ChatGPT Smart Proxy v0.2
========================

一、首次安装
1. 将整个文件夹解压到你准备长期使用的位置。
   支持中文路径和空格，例如：D:\我的工具\AI 工具\ChatGPT代理\
2. 双击 install.cmd。
3. Chrome 打开 chrome://extensions/
4. 开启“开发者模式”，点击“加载已解压的扩展程序”。
5. 选择 install.cmd 自动打开的 extension 文件夹。
6. 固定“ChatGPT 智能代理”扩展。

二、使用
- 点击“添加节点”导入 vless://、vmess://、trojan://，也可粘贴完整 Xray JSON。
- 节点右侧“…”可以：使用、测速、编辑、删除。
- 顶部总开关控制代理启用/停止。
- 推荐分流模式：“仅 ChatGPT / OpenAI”。
- Xray 和本地管理程序均后台运行，不显示黑色命令窗口。

三、目录说明
- ChatGPTProxy.exe：Go 编译的本地管理程序。
- core\xray.exe：Xray Core。
- extension\：Chrome/Edge 扩展，浏览器会持续从这里加载，请不要移动或删除。
- data\：首次运行后自动创建，保存节点、当前配置与日志。

四、卸载
在命令提示符中运行：
  install.cmd uninstall
它会移除开机启动并停止后台程序，但不会删除当前文件夹和节点数据。

五、测速说明
插件中的“测速”是本机到节点服务器端口的 TCP 延迟，用于快速判断节点可达性和大致延迟，
并不等于完整代理协议握手速度或实际下载速度。
