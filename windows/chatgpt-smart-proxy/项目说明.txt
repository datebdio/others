ChatGPT Smart Proxy v0.2.0
==========================

一、项目简介

ChatGPT Smart Proxy 是一个面向 Windows + Chrome/Edge 浏览器的轻量智能代理工具。

它的目标不是替代完整代理客户端，而是在浏览器层面提供更简单的 AI 网站访问分流能力：

- ChatGPT、OpenAI 等 AI 网站自动使用指定代理节点。
- 普通网站保持直连，减少不必要的代理流量。
- 通过浏览器插件管理节点，无需频繁修改系统代理。

二、工作原理

程序由三个部分组成：

1. 浏览器扩展

负责：
- 控制浏览器代理状态。
- 根据访问域名自动选择代理规则。
- 管理节点列表和分流模式。

2. Go 本地管理程序

负责：
- 保存节点配置。
- 生成 Xray 配置。
- 启动和停止 Xray。
- 提供本地管理接口。

3. Xray Core

负责实际网络代理连接，支持：
- VLESS
- VMess
- Trojan
- 完整 Xray JSON 配置

三、主要功能

- ChatGPT/OpenAI 专用分流。
- 常用 AI 网站分流。
- 浏览器全局代理模式。
- 多节点管理。
- 节点添加、编辑、删除、切换。
- 节点 TCP 延迟测试。
- 一键启用/停止代理。
- Windows 后台运行，无黑色命令窗口。
- 支持中文路径和空格路径。

四、适用场景

适合以下情况：

- 日常使用 ChatGPT 等 AI 工具。
- 不希望系统所有软件都经过代理。
- 希望浏览器插件快速切换代理节点。
- 需要一个简单易维护的个人 AI 网络工具。

五、目录结构

ChatGPTProxy.exe
  本地后台管理程序。

core/
  Xray Core 和相关数据文件。

extension/
  Chrome/Edge 浏览器插件。

data/
  运行时生成的数据和日志。

install.cmd
  安装入口。

六、安全说明

- 节点配置只保存在本机。
- 不上传用户节点、密码、UUID 或订阅地址。
- 管理接口仅监听本机地址。
- 使用前请确保节点来源合法并符合当地法律法规。
